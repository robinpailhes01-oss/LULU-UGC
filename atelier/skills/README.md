# Skills de l'Atelier

Le savoir-faire de June, écrit pour l'agent de l'Atelier : styles de montage, voix des légendes,
direction artistique, méthodes de tri et de livraison, règles de programmation, références.

- **Écrits ici** (un dossier par skill : `SKILL.md` + `data.json` facultatif + annexes), regroupés
  au build par `npm run skills:bundle`, importés automatiquement dans l'Atelier.
- **Améliorés dans l'Atelier** (écran « Skills », ou en demandant à l'agent) : chaque
  modification crée une version ; retour arrière possible ; une nouvelle version du dépôt n'écrase
  jamais une modification faite dans l'Atelier (elle est signalée, à récupérer si on le souhaite).
- **Rapatriés ici** avec `npm run skills:pull` pour les relire et les committer.

Mode d'emploi détaillé pour Claude Code : `.claude/skills/atelier-skills/SKILL.md` à la racine du dépôt.

|---|---|---|
| marque-june | Marque | Qui est June, l'offre, les garde-fous |
| direction-artistique | Marque | Lumière, cadrage, palette, typographies des contenus |
| voix-june | Voix | Légendes, hooks, textes à l'écran |
| retouche-june | Retouche | Méthode de retouche, quel look pour quelle scène |
| tri-shooting | Méthode | Ranger, taguer, sélectionner un shooting |
| content-board | Méthode | Livrables Experience Content Day et Content Board |

| reel-immersion | Montage | Reel signature, 15–20 s, lent |
