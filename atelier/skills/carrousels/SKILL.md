# Carrousels

- Format 4:5 (1080×1350) ; toutes les images d'un carrousel ont le même ratio.
- 5 à 10 images ; la première arrête le pouce (la plus forte, la plus lumineuse), la deuxième
  donne envie de continuer (un détail ou un mouvement).
- Raconter dans l'ordre du vécu : arriver, découvrir, profiter, prolonger.
- Varier les plans : large, moyen, détail, puis large à nouveau.
- Texte sur image seulement pour un carrousel d'informations (accès, prestations, horaires) :
  Fraunces pour le titre, Manrope pour le reste, fond crème ou photo floutée.
- Toujours la même retouche sur tout le carrousel.

Types utiles : « Le lieu en 7 images », « Une journée ici », « Les détails », « Infos pratiques ».
